Indicadores BR

Indicadores econômicos do Brasil

Juros, inflação, câmbio, atividade e desemprego num lugar só, a partir das APIs públicas do Banco Central e do IBGE. Os dados passam por um pipeline de engenharia de dados com Airflow e dbt, descrito no fim da página.

Atenção: esta versão foi gerada com dados sintéticos de teste, e não com os dados reais.

Como funciona

Um pipeline ELT que roda localmente com Docker e publica só este site estático. O código é aberto.

Orquestração

DAG mensal com catchup: o backfill desde 2015 é um comando. Uma task por indicador (dynamic task mapping), retries com backoff exponencial e uma janela de 3 meses para trás em cada execução, porque o IPCA sai no mês seguinte e as séries são revisadas.

Carga idempotente

Upsert por (indicador, data) no schema raw. Reexecutar não duplica, e uma revisão da fonte só muda o que mudou. Cada execução fica registrada em raw.cargas, que alimenta o source freshness.

Modelagem

Staging por fonte, um intermediate que leva tudo para a granularidade mensal com a regra de agregação do catálogo, e marts com fct_indicador_mensal incremental, dim_indicador, dim_calendario e o mart do painel.

Qualidade

Testes de chave, relacionamento e faixa plausível; um teste que reconcilia o IPCA de 12 meses publicado com o acumulado das variações mensais; e testes unitários do dbt para o juro real (equação de Fisher).
